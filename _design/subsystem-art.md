# SUBSYSTEM: art

## Summary
A fully file-free rendering layer for a dark horror house. Everything is Three.js geometry + procedural <canvas> textures. The renderer runs ACES Filmic tone mapping in sRGB output color space with PCFSoft 2048px shadows from a SINGLE shadow-casting light (the flashlight) plus baked-feel static point lights that do NOT cast shadows. Heavy exponential fog (FogExp2) hides the far world and saves fill cost. Lighting is intentionally near-black: a tiny hemisphere fill, 3-5 dim warm point lights for pools of light, and a camera-mounted flashlight SpotLight with a multi-octave flicker. All surfaces use MeshStandardMaterial with procedurally generated albedo + roughness + normal maps drawn on offscreen canvases (wood grain, floral wallpaper, woven fabric, tile, brushed metal, plaster, rug) cached in a TextureFactory so each material is generated once and reused. Granny is a hunched old-woman rig built from a THREE.Group of ~30 grouped primitives (sphere head with sculpted brow/nose/jaw, gray hair bun, stooped curved spine of stacked tapered cylinders, dress+apron skirt, two arms, a cane) driven by a manual joint walk cycle (procedural sine-driven hip/knee/elbow/spine sway) and a snap lunge animation. Furniture is a library of ~18 detailed beveled-geometry builders with grime/dust/cobweb decals layered via the texture system. Cheap full-screen post stack: ACES already in renderer, plus a single custom ShaderPass for vignette + film grain + subtle chromatic aberration. Budget: <=120 draw calls, <=350k triangles, ONE shadow-casting light, target 60fps at 1080p on integrated GPUs via merged static geometry, instancing of repeated props, and frustum/distance culling.

## Key Decisions
- ONE shadow-casting light only — the flashlight SpotLight. Every other light (hemisphere, ambient, warm point lights) has castShadow=false. This is the single biggest perf lever; N shadow lights = N extra scene renders per frame.
- ACESFilmicToneMapping + SRGBColorSpace output + colorSpace=SRGB on all albedo canvas textures; normal/roughness/metalness maps stay LinearSRGBColorSpace (data textures, NOT color). Getting this wrong washes out or darkens everything.
- MeshStandardMaterial everywhere (PBR metalness/roughness workflow). Avoid MeshPhongMaterial — it cannot do energy-conserving roughness and looks plastic. Avoid MeshPhysicalMaterial except for window glass (transmission) because clearcoat/transmission are expensive.
- All textures generated ONCE through a memoized TextureFactory keyed by (type, seed, size). Repeated wood/wallpaper share one GPU texture; variation comes from per-mesh UV offset/rotation and material color tint, not new textures.
- FogExp2 (exponential) not linear Fog — it falls off naturally and lets the flashlight beam read as volumetric-ish. Fog color must MATCH renderer.setClearColor and the ambient tone or you get a visible 'fog wall'.
- Static world geometry (walls, floors, large furniture) merged per-material with BufferGeometryUtils.mergeGeometries into a few big meshes to collapse draw calls. Physics colliders stay separate (cannon-es), decoupled from render meshes.
- Repeated identical props (chairs, books, balusters, picture frames) use InstancedMesh, not N separate meshes.
- Granny built from a manual joint hierarchy (nested Groups as pivots) rather than a skinned mesh + bones. No rigging files needed, full control of the hunch, and walk cycle is pure procedural math updated each frame.
- Post-processing is a SINGLE combined ShaderPass (vignette+grain+chromatic aberration in one fragment shader) on top of EffectComposer, not three separate passes — each pass is a full-screen blit.

## Data Model
RenderCore owns: THREE.WebGLRenderer, THREE.Scene, THREE.PerspectiveCamera (fov 70, near 0.05, far 60), EffectComposer + RenderPass + post ShaderPass, FogExp2(0x05060a, density 0.085), clock. TextureFactory owns: Map<string, THREE.CanvasTexture> cache, a seeded PRNG (mulberry32), and a hidden pool of OffscreenCanvas (1024x1024 default, 512 for small props, 2048 only for hero floor/wallpaper). MaterialLibrary owns: Map<string, THREE.MeshStandardMaterial> keyed by surface name; each material references factory textures + a base color tint + roughness/metalness scalars + normalScale. LightingRig owns: HemisphereLight, AmbientLight, array of warm PointLight 'fixtures' (each {light, lampMeshRef, baseIntensity, flickerPhase}), and the Flashlight {SpotLight, target, baseIntensity, on:bool, batteryFlicker state}. Granny model owns: root Group + named joint Groups (pelvis, spine0..2, neck, head, shoulderL/R, elbowL/R, hipL/R, kneeL/R, caneHand) + animation state {phase, speed, mode:'idle'|'walk'|'lunge', lungeT}. FurnitureFactory: pure builder functions returning Group, each tagged with userData.collider describing the cannon-es box(es) for the physics module to consume.

## Public Interface
- createRenderCore(canvas): { renderer, scene, camera, composer, render(dt), resize(w,h) } — configures tone mapping, color space, shadows, fog; render() updates post uniforms (time, grain seed) and calls composer.render().
- TextureFactory.get(type, opts) -> { map, normalMap, roughnessMap } where type ∈ {'wood','wallpaper','fabric','tile','metal','plaster','rug','glass'}; opts={size,seed,tint,scale}. Memoized; returns THREE.CanvasTexture(s) with correct colorSpace, wrapS/T=RepeatWrapping, anisotropy=maxAniso, generateMipmaps=true.
- MaterialLibrary.get(name) -> THREE.MeshStandardMaterial (e.g. 'oakFloor','floralWallpaper','agedPlaster','brassLamp','redRug','windowGlass'). Cached singletons.
- LightingRig.build(scene) -> rig; rig.addFixture(position, color, intensity, lampMesh); rig.update(dt) applies flicker to fixtures and flashlight.
- Flashlight.attachTo(camera); Flashlight.toggle(); Flashlight.update(dt, isMoving) -> runs flicker + battery-low stutter; SpotLight is the ONLY castShadow=true light.
- buildGranny() -> { root:Group, joints, update(dt, state) } where state={mode, moveSpeed, lungeProgress}; update() drives the walk cycle / lunge each frame.
- Furniture builders: buildBed(), buildNightstand(), buildWardrobe(), buildBookshelf(), buildDiningTable(), buildChair(), buildSofa(), buildKitchenCounter(), buildFridge(), buildStove(), buildFloorLamp(), buildTableLamp(), buildRug(), buildPainting(), buildDoor() (returns {group, hingePivot, colliderBody-spec}), buildWindow(), buildStairs(). Each returns a THREE.Group with userData.collider.
- WorldMerger.finalize(scene) -> walks tagged-static meshes, groups by material, calls mergeGeometries, replaces them with merged meshes to minimize draw calls. Returns stats {drawCalls, triangles}.

## Tunables
- renderer.toneMapping = ACESFilmicToneMapping; renderer.toneMappingExposure = 0.85 (unitless) — dark mood, raise to 1.0 if too murky
- renderer.outputColorSpace = SRGBColorSpace; renderer.shadowMap.type = PCFSoftShadowMap
- renderer.setPixelRatio(min(devicePixelRatio, 1.5)) — cap at 1.5 to protect fill rate on hi-DPI
- camera: fov=70 deg, near=0.05 m, far=60 m
- FogExp2 color=0x05060a, density=0.085 per meter (visibility ~25-30 m)
- scene clear color = 0x05060a (MUST equal fog color)
- HemisphereLight: sky=0x202838, ground=0x0a0806, intensity=0.12
- AmbientLight: 0x14161f, intensity=0.06 (floor brightness so pure-black corners aren't 0,0,0)
- Warm PointLight fixtures: color=0xffb060, intensity=6-12 (candela-ish, physically-correct off), distance=7 m, decay=2; 3-5 of them; castShadow=FALSE
- Flashlight SpotLight: color=0xfff0d8, intensity=110 (decay=2), distance=22 m, angle=0.42 rad (~24 deg), penumbra=0.55, castShadow=TRUE
- Flashlight shadow.mapSize=2048x2048, shadow.bias=-0.0008, shadow.normalBias=0.04, shadow.camera.near=0.2, far=22
- Flashlight flicker: base*[1 + 0.04*sin(t*13) + 0.03*sin(t*31) + noise()*0.05]; battery-low mode adds random 60-140ms dropouts
- Texture sizes: 2048 hero floor/wallpaper, 1024 default, 512 small props; anisotropy = renderer.capabilities.getMaxAnisotropy() (usually 16)
- Material defaults: wood roughness 0.65 metalness 0.0; plaster rough 0.92 metal 0.0; brass rough 0.35 metal 1.0; tile rough 0.25; fabric rough 0.95; glass MeshPhysicalMaterial transmission 0.9 roughness 0.05 ior 1.5
- normalScale = (0.6,0.6) walls, (1.0,1.0) wood/tile, (0.3,0.3) fabric
- Post: vignette radius=0.75 softness=0.45 strength=0.7; grain intensity=0.045 (animated); chromatic aberration offset=0.0016 (screen-edge scaled)
- Granny scale: standing height 1.55 m but hunched effective eye height ~1.25 m; spine forward lean 38 deg
- Walk cycle: stride freq = moveSpeed/0.7; hip swing +-22 deg, knee 0..52 deg, elbow 8..28 deg, spine bob 0.03 m, cane tap synced to opposite foot
- Lunge: 0.35 s ease-out, torso pitch +18 deg, lead arm extends 0.45 m, forward reach +0.6 m
- Budget: <=120 draw calls, <=350k tris, <=24 textures resident, single shadow pass

## Algorithms
- Renderer init order: create WebGLRenderer({antialias:true, powerPreference:'high-performance'}); set outputColorSpace, toneMapping, exposure, shadowMap.enabled=true + type; create scene + FogExp2; create camera; build EffectComposer with RenderPass then the combined post ShaderPass; on resize update renderer size, composer size, camera aspect, and post uResolution uniform.
- Per-frame render(dt): 1) LightingRig.update(dt) -> for each fixture compute intensity = base*(1+flickerNoise); flashlight.update(dt,isMoving). 2) granny.update(dt,state). 3) post uniforms uTime+=dt, uGrainSeed=random. 4) composer.render(). NEVER call renderer.render() directly when composer exists.
- Procedural wood grain (canvas): fill base brown; loop y rows, draw long horizontal bezier 'grain lines' with sinusoidal warp + 1D value-noise jitter; overlay darker knots as radial gradients at random points; multiply a fine fbm noise for fiber; export as albedo. Generate matching normal map by computing per-pixel luminance gradient (Sobel) of a height field built from the same grain noise -> RGB = normalize(-dx,-dy,strength). Roughness map = inverted grain darkness so knots read rougher.
- Procedural wallpaper: tile a repeating floral/damask motif drawn with paths + symmetry (mirror across vertical center), faded sepia palette; overlay vertical 'water stain' gradients near top, peeling-corner darkening; low normalScale for subtle relief; add grime fbm multiply.
- Procedural tile: draw grid of squares with 2-4 px dark grout gaps; per-tile slight color jitter + speckle noise; normal map: grout lines = deep grooves (height step), tile faces near-flat with micro speckle; roughness low on tile, high in grout.
- Procedural fabric/rug: weave pattern = two interleaved sine gratings (warp+weft) modulated to look threaded; rug adds a bordered medallion pattern with palette of dusty reds/golds; high roughness, soft normal from weave height.
- Procedural metal (brass/steel): base mid value + brushed streaks (1D noise stretched along one axis) + edge tarnish darkening via vignette mask; high metalness, low-mid roughness, faint normal streaks.
- Procedural plaster: fbm noise base near-white-gray + sparse crack lines (random-walk dark strokes branching) + corner grime gradients; strong normal from the fbm height for orange-peel texture.
- Grime/dust/cobweb decal pass (shared): a translucent overlay drawn onto any albedo canvas — dust = soft light-gray fbm at top-facing edges, cobwebs = draw thin radial line bundles + connecting catenary curves in corners with low alpha, then composite multiply/screen before texture upload.
- Normal-map-from-heightfield helper: given a Float32 height canvas H, for each pixel compute dx=H[x+1]-H[x-1], dy=H[y+1]-H[y-1]; n=normalize(vec3(-dx*scale,-dy*scale,1)); write (n*0.5+0.5) to RGB; set texture colorSpace=LinearSRGB (NOT sRGB).
- Granny build: nest Groups so each joint Group sits at its pivot and children are offset by bone length. Spine = 3 stacked tapered CylinderGeometry segments each pre-rotated to form the hunch curve. Head = SphereGeometry scaled, with added small spheres/boxes for nose, brow ridge, cheeks, and a flattened sphere bun; sunken eyes = two dark inset spheres. Dress = lathe/cone skirt (LatheGeometry from a profile) + torso cylinder; apron = thin rounded box plane. Arms/legs = tapered cylinders with sphere joints. Cane = thin cylinder + sphere handle parented to caneHand.
- Walk cycle update: phase += dt*strideFreq; hipL.rot.x = sin(phase)*hipSwing; hipR opposite; knee bend = max(0,-cos(phase))*kneeMax (bend on backswing); elbow/shoulder swing opposite to same-side hip; spine0.position.y = bob*abs(sin(phase*2)); whole root gets a slight side-roll = sin(phase)*3deg for limp; cane taps down synced to weaker leg. Lerp all joints toward targets (damping 12/s) so transitions between idle/walk/lunge don't pop.
- Lunge update: on enter, capture pose; over lungeT in [0,0.35], ease-out torso pitch +18deg, lead shoulder+elbow extend reach forward, root translate +0.6m along facing; after, blend back to walk.
- WorldMerger.finalize: collect meshes with userData.static===true, bucket by material.uuid, for each bucket clone+apply matrixWorld to geometries, mergeGeometries, create one Mesh, dispose originals. Re-tag merged mesh frustumCulled=true. Report draw call count.

## Pitfalls
- Washed-out / glowing scene: forgetting outputColorSpace=SRGBColorSpace, or NOT marking albedo CanvasTextures colorSpace=SRGBColorSpace. Fix: set renderer.outputColorSpace once, and texture.colorSpace=SRGBColorSpace for ALL color maps, LinearSRGBColorSpace for normal/roughness/metalness/height data maps. Test: a mid-gray wall should read mid-gray, not blown out.
- Flat plastic look: using MeshPhongMaterial or leaving roughnessMap null so everything is uniformly shiny. Fix: MeshStandardMaterial + per-surface roughness map; vary roughness 0.25 (tile) to 0.95 (fabric).
- Blue/inverted normals: writing the normal map with sRGB encoding or a flipped green channel. Fix: normal/roughness textures MUST be LinearSRGBColorSpace; if relief looks inverted flip normalScale.y sign. Three.js expects +Y-up (OpenGL) normals.
- Shadow acne / peter-panning: default bias. Fix: shadow.bias=-0.0008 AND shadow.normalBias=0.04; tighten shadow.camera near/far to the flashlight range (0.2..22) so depth precision is spent where it matters.
- Tanking FPS from shadows: giving point lights castShadow=true (each = a full cubemap render = 6 passes). Fix: ONLY the flashlight casts shadows. All ambient/hemisphere/point fixtures castShadow=false.
- Visible 'fog wall' or color mismatch: fog color != clear color != ambient tone. Fix: set scene clear color, FogExp2 color, and hemisphere/ambient tints to the same near-black blue (0x05060a). With far=60 and density 0.085, the far plane is fully fogged so nothing pops in.
- Texture seams / shimmer: forgetting RepeatWrapping (textures clamp and stretch) or anisotropy=1 (grazing-angle floor shimmers). Fix: wrapS/wrapT=RepeatWrapping, set .repeat per surface size, anisotropy=getMaxAnisotropy(), generateMipmaps=true, minFilter=LinearMipmapLinear.
- Memory blowup / stutter: regenerating a 2048 canvas per object. Fix: TextureFactory memoizes; reuse one texture across many meshes, vary via material color tint and per-mesh uv offset. Cap resident textures <=24.
- Granny looks like a stack of cylinders / robotic walk: joints rotating around the wrong pivot and linear (no easing) motion. Fix: each joint is its own Group positioned AT the pivot with child geometry offset by bone length; drive with sin/cos and damped lerp; add spine hunch + side-roll limp + cane so silhouette reads as an old woman, never symmetrical/upright.
- Items floating or clipping (cross-cutting but art-relevant): building furniture with origin at geometry center then placing at floor y. Fix: build each furniture Group so its base sits at local y=0 (feet on the ground plane) and export an accurate userData.collider AABB to the physics module so placement validation matches the visible mesh.
- Draw-call explosion: one Mesh per book/baluster/picture. Fix: InstancedMesh for repeats and WorldMerger for static walls/floors; verify renderer.info.render.calls <=120 in dev HUD.
- Post-processing too expensive or banding: stacking 3 separate passes and using 8-bit buffers. Fix: ONE combined post shader; use HalfFloatType render targets in EffectComposer to avoid tone-mapping banding; keep grain/CA cheap (no blur, no extra texture taps beyond 3 for CA).
- Antialiasing lost with EffectComposer: composer bypasses the renderer's MSAA. Fix: either accept the post-pass FXAA-style smoothing, or use WebGLRenderTarget with samples>0 (MRT/MSAA RT) for the RenderPass on WebGL2.
- Over-bright flashlight clipping detail: intensity too high with decay=2 makes near surfaces pure white. Fix: tune intensity ~110 with toneMappingExposure 0.85; let ACES roll off highlights; add penumbra so the cone edge is soft not hard.

## Risks
- Procedural texture generation cost at load: drawing ~24 canvases (several 2048) plus Sobel normal passes can freeze the main thread for hundreds of ms. Mitigation: generate during a loading screen, time-slice across frames or use OffscreenCanvas in a Worker; precompute on first run and keep in cache.
- Integrated-GPU fill rate: heavy fog + soft shadows + post on a low-end laptop may miss 60fps at 1080p. Mitigation: pixelRatio cap 1.5, dynamic resolution scaling, optional 'low' mode dropping shadow map to 1024 and disabling chromatic aberration.
- Single shadow light limits realism: only flashlight-cast shadows means lamps don't shadow. Acceptable for mood and budget; document as intentional. If needed later, add ONE static baked-direction shadow but never per-point-light shadows.
- Manual joint Granny may look stiff vs a skinned mesh, especially at limb joints (visible gaps). Mitigation: overlap sphere 'joint caps' at every pivot, slight geometry interpenetration, and a cloth-like skirt that hides hip motion.
- Color-space and tone-mapping interactions are subtle; a single wrong colorSpace flag silently degrades the whole look. Mitigation: a debug overlay that renders a known color chart to verify the pipeline, and a checklist test before sign-off.
- WebGL2 assumption: MSAA render targets, HalfFloat, and high anisotropy assume WebGL2; on rare WebGL1 fallback some features degrade. Mitigation: feature-detect and fall back gracefully (no MSAA RT, 8-bit buffers, lower aniso).
- Texture memory budget on mobile/integrated: 2048 maps x multiple (albedo+normal+rough) can exceed VRAM. Mitigation: cap hero 2048 textures to floor+main wallpaper only, everything else <=1024, share aggressively.

## CRITIQUE (worksProbability=0.25)
Verdict: CONDITIONAL REJECT. The rendering pipeline knowledge is genuinely solid — color space, tone mapping, single-shadow-light strategy, memoized TextureFactory, and PBR roughness ranges are all correct and would pass review in isolation. But three things will break the integrated build and one will not be fun, and they are exactly the things the client is furious about. (1) The performance budget is fictional: it counts draw calls (the wrong metric for integrated GPUs) while the real killer — fill rate from PCFSoft-2048 shadows + FogExp2 + a full-screen post blit at 1080p — is hand-waved into a 'low mode' footnote. This will not hold 60fps on Intel Iris/UHD. (2) The art subsystem decouples physics colliders from merged render geometry with NO stated reconciliation step, which is the precise mechanism that produces floating/clipping items — the #2 hard requirement. The design even names this pitfall, then does not provide the closing-the-loop algorithm. (3) The manual-joint Granny is admitted-stiff and the mitigation ('joint caps, interpenetration, skirt') is the standard hand-wave that produces a stack of cylinders, which is requirement #4's explicit failure mode. (4) Several lighting numbers are internally inconsistent (fog density vs far plane, flashlight 110cd vs ACES exposure 0.85) and will need empirical recalibration the design pretends is already done. The fix list below makes it buildable, but as written this fails an integrated smoke test.

### Fatal Flaws
- PERF BUDGET MEASURES THE WRONG THING. The budget is <=120 draw calls / <=350k tris, but integrated GPUs (Intel Iris Xe, UHD 630) are fill-rate and bandwidth bound, not draw-call bound. The actual per-frame cost is: 1x shadow depth pass at 2048x2048 PCFSoft (each lit fragment does up to 16-25 depth taps) + opaque pass with FogExp2 (per-fragment exp) + a full-screen EffectComposer blit through HalfFloat targets + the combined post shader (vignette+grain+3-tap chromatic aberration). At native 1080p (2.07M px) with pixelRatio 1.5 you are shading ~4.6M fragments before overdraw. On an Iris Xe that is ~30-45fps, not 60. The design's only answer is an optional 'low mode' — that means the DEFAULT mode misses the stated target on the stated hardware. This is the single biggest credibility problem.
- PHYSICS/RENDER GEOMETRY DECOUPLING IS THE FLOATING-ITEM BUG, NOT THE FIX. WorldMerger.finalize bakes matrixWorld into merged render meshes, while furniture exports userData.collider AABBs that the physics module consumes SEPARATELY. There is no algorithm that re-reads the final merged/placed transforms back into the collider spec. Any rounding, any post-merge nudge, any builder whose visible mesh base is not exactly at the collider base = items rest on a surface the player sees 1-3cm off, or sink/clip. The design lists 'items floating' as a pitfall and gives the right principle (base at local y=0) but never specifies the validation that proves render-mesh-top == collider-top == item-rest-Y at runtime. Requirement #2 says placement must be 'collision-validated' and 'deterministic'; this subsystem provides neither hook.
- MANUAL-JOINT GRANNY WILL LOOK LIKE A STACK OF CYLINDERS. ~30 grouped primitives with sphere joint caps and 'slight geometry interpenetration' is exactly the technique that produces visible seams, popping at the shoulder/hip, and a rigid silhouette when limbs swing +-22deg. Tapered cylinders do not deform; at a 22-degree hip swing the thigh-pelvis junction opens a gap a sphere cap only half-hides, and from the front the body reads as segmented. The design flags this as a risk and then offers no concrete geometry that survives motion. Requirement #4 explicitly says 'Granny must read as a hunched old woman, not a box' — a non-skinned primitive rig is the highest-risk path to violating exactly that.
- FOG vs FAR-PLANE MATH IS WRONG AND THE STATED GUARANTEE IS FALSE. FogExp2 factor = 1 - exp(-(density*dist)^2). At density=0.085, dist=60: (5.1)^2=26 -> exp(-26) ~ 5e-12, so yes fully fogged at 60m. BUT visibility is effectively gone by ~25m (at 25m: (2.125)^2=4.5, exp(-4.5)=0.011, i.e. 99% fogged). So far=60 renders 25-60m of fully-fogged geometry every frame for ZERO visual benefit — pure wasted fill/vertex work, directly contradicting the perf budget. The claim 'with far=60 and density 0.085 the far plane is fully fogged so nothing pops in' is half-true but self-defeating: cull at far=28-30 instead. Exp2 fog also never multiplies geometry out of the draw — fogged tris are still rasterized.

### Concrete Fixes
- Re-anchor the perf budget on fill rate. Set DEFAULT renderer.setPixelRatio(min(devicePixelRatio,1.0)) — drop the 1.5 cap to 1.25 only on dedicated GPUs detected via WEBGL_debug_renderer_info. Drop flashlight shadow.mapSize to 1536x1536 default (2048 only on 'high'). Add a dynamic-resolution controller that scales the RenderPass target from 0.7x to 1.0x to hold a 16.6ms frame, measured by a 30-frame rolling average. Set camera far=30 and FogExp2 density=0.10 (visibility ~22m, matches shadow range 22m). This makes 60fps on Iris Xe plausible; verify with renderer.info plus an actual frame-time HUD, not draw-call count.
- Close the physics/render loop explicitly. After WorldMerger.finalize AND after furniture placement, run a reconciliation pass: for every placeable surface, raycast straight down from item spawn point against the FINAL physics world (cannon-es), get the contact Y, and set item.position.y = contactY + itemHalfHeight + 0.001. Author every furniture builder so geometry base AND collider base are both at local y=0 with a unit test asserting box3.min.y === 0 (within 1e-4) for each builder's merged geometry. Never trust authored rest heights; always re-derive from the physics raycast at runtime so render/physics drift is impossible by construction.
- Replace the primitive Granny with a low-poly SKINNED mesh built procedurally. You do NOT need asset files for skinning: build one merged BufferGeometry for the body (LatheGeometry torso+skirt, capsule limbs), generate skinIndex/skinWeight arrays in code by assigning each vertex to the nearest 1-2 bones with smoothstep falloff across joint boundaries, build a THREE.Skeleton from ~12 Bones, and create SkinnedMesh. This removes ALL joint-gap and popping problems, keeps full procedural control of the hunch (bend the spine bones), and the walk cycle drives bone quaternions instead of group rotations. Budget ~3-5k tris for her. If the team truly refuses skinning, cap hip swing at 12deg (not 22), put her in a floor-length skirt that fully occludes both legs below mid-thigh, and never show her full-body in good light.
- Recalibrate lighting empirically and document the test scene. Flashlight: with decay=2 and ACES exposure 0.85, intensity 110cd makes a wall at 1.5m ~ 110/2.25=49 -> blown white. Start at intensity 40cd, distance 22, then tune against a mid-gray (sRGB 0.5) test wall at 2m reading ~0.45-0.55 post-tone-map. Warm point fixtures at intensity 6-12cd/distance 7 with decay=2 give ~0.12-0.24 at 7m — too dim to read as 'pools of light'; raise to 15-25cd or shorten distance to 4-5m. Provide the debug color-chart overlay the design mentions as a REQUIRED dev tool, not an optional one, and gate sign-off on it.
- Fix the post stack for both AA and cost. EffectComposer with a RenderPass bypasses the renderer's MSAA, so the scene will alias badly (high-contrast flashlight edges in the dark = crawling jaggies). Use a WebGL2 multisampled WebGLRenderTarget (samples=4) for the RenderPass input, OR put the post chain BEFORE an SMAA/FXAA-as-final-pass. Use HalfFloatType targets (already specified — good, prevents tone-mapping banding). Keep chromatic aberration to 3 taps max and scale offset by radial distance so center is sharp; 0.0016 is fine. Add an off switch for CA in low mode.
- Time-slice texture generation to avoid the load freeze. Generating ~24 canvases including several 2048 + Sobel normal passes synchronously freezes the main thread 300-800ms. Generate inside requestIdleCallback/rAF chunks (one texture per frame) behind the loading screen, OR move generation to an OffscreenCanvas in a Worker and transfer ImageBitmaps. Hard-cap 2048 to floor + primary wallpaper only (2 textures); everything else 1024 or 512. Set minFilter=LinearMipmapLinearFilter, generateMipmaps=true, anisotropy=getMaxAnisotropy() — already specified, keep it.

### Missing Details
- No frame-time measurement plan. The budget is asserted in draw calls/tris but there is no stated method to measure actual ms/frame on target hardware, no list of the target integrated GPUs, and no pass/fail gate. 'Target 60fps on integrated GPUs' is untestable as written.
- No specification of how the merged-static color tint variation works post-merge. The design says variation comes from 'per-mesh UV offset/rotation and material color tint, not new textures', but after BufferGeometryUtils.mergeGeometries collapses meshes by material.uuid, per-mesh material tint is GONE (they now share one material). Either tint must be baked into a vertex-color attribute before merge, or UV offset baked per-vertex — neither is specified. As written, all merged walls will be identical.
- InstancedMesh + per-instance physics is unaddressed. Books/balusters/picture frames as InstancedMesh share one draw call, but each still needs (or doesn't need) a cannon-es body. The design never says which instanced props are static decoration vs interactable/pushable, and the player can only 'push furniture' if those have real bodies — there's no mapping from instance index to physics body.
- Shadow camera for a SpotLight is a perspective frustum, not the near/far box implied. shadow.camera.near/far=0.2/22 is correct, but the design omits that SpotLight shadow FOV is derived from light.angle (0.42rad) — with penumbra 0.55 the shadow map only covers the cone, so anything lit by ambient/point fixtures OUTSIDE the flashlight cone casts NO shadow at all. This means Granny standing in a lamp's pool of light is shadowless and will look pasted-on. Not acknowledged.
- No LOD or culling strategy for Granny or furniture beyond 'frustumCulled=true'. Distance culling is mentioned once with no distances. In a multi-room house with FogExp2, occluded rooms are still in the draw list (no portal/room culling), so the 120-call budget assumes the whole house is always submitted — contradicting the budget on a large level.
- Window glass uses MeshPhysicalMaterial transmission 0.9 — transmission requires a transmissionRenderTarget (an extra scene render of what's behind the glass) which is one of the most expensive features in Three.js and directly contradicts the 'avoid expensive transmission' decision stated two bullets earlier. For dark horror windows, a cheap MeshStandardMaterial with low opacity + envMap fake is enough; real transmission should be cut.
- No memory accounting. 'Cap resident textures <=24' but with albedo+normal+roughness per surface that's potentially 24 surfaces x 3 maps. At 1024 RGBA + mipmaps that's ~5.3MB each -> 70+ maps could approach 350-400MB VRAM, over budget on shared-memory integrated GPUs. The cap should be on total bytes, not texture count.
