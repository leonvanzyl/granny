# COMPONENT: visuals

## Summary
Drive EVERYTHING off one scalar dread (0..1). main.js computes it from data already on hand and pushes it each frame via a new core.setDread(dread,dt); render.js smooths it with asymmetric attack/release and feeds every visual system. Every look is a lerp between a CALM grade and a DREAD grade by this scalar. NO new pipeline: grade/grain/vignette-breath/halation are appended to the existing PostShader.fragmentShader (the same single full-screen pass already in the composer). Light failure rides inside the existing updateLighting() loop. Fog is the existing FogExp2 with animated density+color. Budget cost is ~25 extra ALU ops + 4 extra texture taps/pixel (halation is the only real cost) and is gated OFF on mobile. Desktop holds 60fps; mobile gets a stripped grade, lower grain, no halation, no hard light dropouts. DREAD SOURCE in main.js stepGame next to the heartbeat block (~lines 247-252): aware=G.granny.awareness01(); dist=G.granny.distToPlayer; prox=clamp01((12-dist)/12); dread=clamp01(0.55*aware+0.45*prox); chasing is already computed there, so dreadTarget = chasing ? 1.0 : dread; then call core.setDread(dreadTarget, dt). dist can be Infinity early; clamp01 already guards prox, but also guard setDread against non-finite. Smoothing happens INSIDE core, not main.js, so main stays a one-liner.

## Key decisions
- ONE driver scalar dread in [0,1], smoothed INSIDE core with asymmetric time constants: rise TC 0.30s, fall TC 1.8s. d += (target-d)*(1-Math.exp(-dt/tc)) with tc = (target>d ? 0.30 : 1.8). Fast spike, slow bleed-off = the SH 'dread lingers' feel. Store as core._dread and feed it to uniform uDread and to updateLighting.
- Reuse the existing single PostShader pass 1:1. Append ALL grade/grain/vignette/halation math to PostShader.fragmentShader. New uniforms: uDread(float), uResolution(vec2), uDesat(vec2 calm/dread), uLift(vec2), uTintShadow(vec3), uTintHi(vec3), uTintAmt(vec2 calm/dread), uHalation(float), uBreathRate(float), uMobile(float 0/1). Pipeline cost stays identical except per-pixel ALU + 4 taps.
- Color grade ordering in the fragment, AFTER the chroma fetch and BEFORE the final vignette: 1) luma=dot(col,vec3(0.299,0.587,0.114)); 2) desaturate col=mix(col,vec3(luma),mix(uDesat.x=0.25,uDesat.y=0.62,uDread)); 3) lift+crush col=col*0.92+mix(uLift.x=0.018,uLift.y=0.045,uDread) (gain 0.92 crushes highlights, additive lifts blacks = flat SH 'ash' look); 4) 2-color tint tw=mix(uTintAmt.x=0.10,uTintAmt.y=0.30,uDread); tint=mix(uTintShadow,uTintHi,smoothstep(0.15,0.85,luma)); col=mix(col,col*tint*2.0,tw). uTintShadow=vec3(0.18,0.22,0.12) sickly olive; uTintHi=vec3(0.62,0.55,0.40) jaundiced sepia (x2 so neutral~=1.0, only chroma bends).
- Coarse film grain: keep existing rand() but (a) quantize uv into chunky cells cell=floor(vUv*uResolution*grainScale), grainScale 0.85 desktop / 0.50 mobile, so grain is 16mm-print chunky not TV-snow fine; (b) amplitude gAmp=mix(0.045,0.090,uDread) desktop, fixed 0.035 mobile; (c) faint vertical scanline col*=1.0-0.04*uDread*step(0.5,fract(vUv.y*uResolution.y*0.5)) desktop only. Seed = cell + uTime*60.0 (additive so it animates; main already wraps t%1000).
- Breathing vignette: modulate the radius in-shader. br=uVignette.x - mix(0.0,0.06,uDread)*0.5 - (0.025+0.03*uDread)*sin(uTime*uBreathRate*6.2831); vstr=mix(uVignette.z=0.70,0.92,uDread). uBreathRate set in setDread: 0.18Hz calm (slow breath) to 0.50Hz dread (panting). This is the P.T. 'walls breathe' pulse.
- Cheap halation (DESKTOP ONLY, if(uMobile<0.5)): 4-tap bright-pass of tDiffuse itself, NO extra RT. After grade: bp(c)=max(c-0.65,0); sum 4 diagonal taps at +/-3 texels, *warm tint vec3(0.62,0.55,0.40), *uHalation; add to col. uHalation=mix(0,0.35,uDread). Only the flashlight hotspot + fixtures bleed a warm glow. 4 taps total, negligible; forced 0 + branched out on mobile.
- Failing flashlight (replace the existing flick line ~123-124): keep two sines, add brown-noise core._fnoise=core._fnoise*0.92+(Math.random()-0.5)*0.10; flick=1+0.04*sin(t*13)+0.03*sin(t*31)+core._fnoise*(0.10+0.35*dread). Scripted hard dropouts via core._dropT countdown: if _dropT<=0 and Math.random()<dt*(0.15+2.2*dread*dread) start dropout _dropT=0.08+rand*0.14 (80-220ms); while active multiply intensity *0.04 (near-black, NOT 0, to keep shadow map warm); decrement _dropT by dt. Probability scales dread^2 so she 'kills the lights' when near.
- Failing fixtures (existing fixtures loop): sag base by dread sag=1-0.55*dread (down to 45%); buzz=1+0.05*sin(t*11+f.phase)+0.03*sin(t*27)+dread*0.18*sin(t*100+f.phase) (the t*100 term ~16Hz electrical buzz appears only under dread); f.light.intensity=f.base*sag*buzz. Per-fixture rare 1-frame blackout: if Math.random()<dt*1.5*dread*dread set intensity 0 that frame. The P.T. 'lights die when she is near' beat, zero scripting infra.

## Data model
core gains internal fields (no external schema): core._dread (smoothed 0..1), core._dreadTarget, core._fnoise (brown-noise accumulator, init 0), core._dropT (flashlight dropout countdown, init 0), core._breathRate (Hz, init 0.18), core._res (THREE.Vector2 of drawing-buffer size), core._dreadFed (bool flag per frame for menu/pause decay-to-calm), core._fogBase (0.16). PostShader.uniforms gains: uDread{value:0}, uResolution{value:new THREE.Vector2(w,h)}, uDesat{value:new THREE.Vector2(0.25,0.62)}, uLift{value:new THREE.Vector2(0.018,0.045)}, uTintShadow{value:new THREE.Color(0.18,0.22,0.12)}, uTintHi{value:new THREE.Color(0.62,0.55,0.40)}, uTintAmt{value:new THREE.Vector2(0.10,0.30)}, uHalation{value:0}, uBreathRate{value:0.18}, uMobile{value:mobile?1:0}. All defaults belong in config.js RENDER.post as new keys: desatCalm,desatDread,liftCalm,liftDread,crushGain,tintShadow,tintHi,tintAmtCalm,tintAmtDread,halationMax,brightThreshold,halTexel,breathRateCalm,breathRateDread,grainCalm,grainDread,grainMobile,grainScale,grainScaleMobile,vignetteStrengthDread. Plus RENDER.fogDensity bumped 0.10->0.16 and new RENDER.fogDensityDread=0.03, RENDER.fogColorDread=0x0a0c08, fog roll freqs 0.13Hz density / 0.09Hz color.

## Algorithms
- Asymmetric 1-pole dread smoothing: tc=(target>d)?0.30:1.8; d += (target-d)*(1-Math.exp(-dt/tc)). Frame-rate independent (uses real dt). Fast attack, slow release.
- Brown-noise flicker: _fnoise=_fnoise*0.92+(Math.random()-0.5)*0.10. Leaky integrator of white noise = 1/f-ish flicker, creepier than per-frame white; variance bounded ~+/-0.3 by the 0.92 leak.
- Poisson-style dropout gating: per-frame probability p=dt*lambda. Flashlight lambda=0.15+2.2*dread^2 events/s; fixture lambda=1.5*dread^2. Using dt keeps the rate frame-rate independent. Flashlight dropout duration 80-220ms; never fully 0 (use *0.04) so PCFSoftShadow map stays valid and reads as guttering.
- Quantized chunky grain: cell=floor(vUv*uResolution*grainScale); g=(rand(cell+uTime*60.0)-0.5)*gAmp; grainScale<1 enlarges cells = coarse film grain. Amplitude lerped calm->dread.
- Luma-keyed 2-color tint: t=smoothstep(0.15,0.85,luma); tint=mix(shadowTint,hiTint,t); col=mix(col,col*tint*2.0,amt). Shadows go olive, mids/highs go jaundiced sepia = SH 'rust and bile'.
- 4-tap halation (no separable blur, no RT): bp(c)=max(c-0.65,0); sum = bp(tex(+du,+dv))+bp(tex(-du,-dv))+bp(tex(+du,-dv))+bp(tex(-du,+dv)); col += sum*warm*uHalation, du=dv=3 texels = 3.0/uResolution.
- Fog density roll: density=base*(1+0.06*sin(t*0.13))+dreadBump*dread, clamped <=0.22 so a target at 6-8m stays legible (exp(-0.22*8)=0.17 transmittance).
- Fog color creep: lerpColors(BASE_FOG,DREAD_FOG, slow sine + 0.4*dread); background copies fog color to kill horizon seam.

## Mobile fallback
mobile is already detected in createRenderCore (the `mobile` const). Pass uMobile=mobile?1:0 to the shader. When uMobile>0.5: (1) halation block fully branched out via if(uMobile<0.5){...} - zero extra texture taps; (2) grain fixed 0.035 with coarse grainScale 0.50 and NO scanline term; (3) tint amount capped at tintAmtCalm (0.10) and desat capped ~0.40 (clamp the mix factor) - cheaper, less-saturated grade; (4) chroma left as-is (already cheap). In updateLighting on mobile: SKIP hard dropouts entirely (no per-frame Math.random branch storm); flicker reduces to the existing two-sine flick scaled lightly by dread; fixtures use sag only, no 16Hz buzz, no blackout. Fog: keep the heavier base density 0.16 (it REDUCES overdraw by fog-culling distant fragments = net mobile win) but set fog color once (skip the per-frame lerp). All toggled by the existing `mobile` boolean - no new detection. Net mobile cost: only the desat+lift+light-tint grade (~6 ALU ops) plus heavier fog, both effectively free; halation, scanlines, buzz, and dropouts all off.

## Pitfalls
- distToPlayer is Infinity/undefined before granny spawns or between runs: prox via clamp01((12-Infinity)/12)=0 is safe, but ALSO guard setDread with if(!isFinite(target)) target=0. And in menu/pause main.js does not call setDread, so dread would freeze; FIX: in core.render, if no setDread happened this frame call core.setDread(0,dt) so menus/pause bleed to calm (the _dreadFed flag).
- uResolution MUST be the DRAWING BUFFER size (renderer.getDrawingBufferSize), not innerWidth, because pixelRatio differs; otherwise grain cell size and halation texel are wrong. Set it at construction AND in resize().
- Forcing flashlight.intensity to literal 0 during a dropout can make THREE skip the shadow pass -> 1-frame shadow pop on return; use *0.04 (near-black). Never toggle castShadow.
- This post pass runs BEFORE OutputPass, so it operates on the linear-ish HalfFloat scene color, NOT tone-mapped sRGB. Apply the grade in that linear space and verify the bright-pass threshold 0.65 against the actual flashlight hotspot luminance; OutputPass does the ACES+sRGB, do NOT double tone-map. Retune thresholds after seeing the final image.
- scene.background and scene.fog.color must stay in sync each frame or the far horizon shows a hard seam (geometry fog-fades to fog.color, cleared background is the old color). Copy fog.color into background after the lerp.
- Animating FogExp2.density upward can over-fog granny at her ~12m visionRange approach; CAP effective density <=0.22 (transmittance at 8m = exp(-0.22*8)=0.17, still visible). Do not let the dread bump + roll exceed that.
- Grain seed must include uTime additively (cell+uTime*60.0), not as a multiplier on the cell, or a paused/static frame shows frozen grain. main.js already wraps t with t%1000 before render - keep that to bound the hash.

## CRITIQUE worksProb=0.72
### Fatal flaws
- GRAIN SEED PRECISION — THE design's own grain formula will freeze/strobe, contradicting its anti-freeze pitfall. `t = now() = performance.now()/1000` (seconds), bounded by the EXISTING `t % 1000` in core.render. So `uTime` is 0..1000 and `uTime*60.0` is 0..60000. In float32, `rand(c)=fract(sin(dot(c,vec2(12.9898,78.233)))*43758.5453)` with an argument component near 60000 loses all sub-integer resolution: sin's argument is ~(60000+cell)*~91, the *43758 product overflows 24-bit mantissa, and consecutive frames (delta ~0.016 in uTime => delta ~1.0 after *60) land on near-identical hashes. Result: grain that updates in chunky jumps or appears frozen — exactly the failure the design says it avoids. The existing shader has the same latent bug but at 0.045 amplitude nobody noticed; at 0.090 dread amplitude it will be obvious.
- FOG CAP MATH IS WRONG / TOO AGGRESSIVE — design caps density <=0.22 and claims 'transmittance at 8m = exp(-0.22*8)=0.17, still visible'. FogExp2 transmittance is exp(-(density*dist)^2), NOT exp(-density*dist). Correct value: exp(-(0.22*8)^2)=exp(-3.10)=0.045 — Granny at 8m is 95% fogged, effectively invisible during the approach the whole feature is built around. Even at her 6m dark-vision range: exp(-(0.22*6)^2)=exp(-1.74)=0.18. The base bump from 0.10->0.16 alone changes 8m transmittance from exp(-(0.8)^2)=0.53 to exp(-(1.28)^2)=0.19. This will hide the antagonist and tank readability. The cap and the prose are both computed with the wrong fog model.
- FIXTURE PHASE ALREADY ACCUMULATES RANDOM DRIFT — updateLighting line 115 does `f.phase += dt*(2+Math.random()*0.5)`. The design layers a new `t*100` (16Hz) buzz and per-fixture `Math.random()<dt*1.5*dread^2` blackout ON TOP of an already-randomized phase. Combined with the flashlight brown-noise + Poisson dropouts, under a latched chase (dread=1.0) you get the whole room strobing every frame from 4+ independent random sources. This is both an epilepsy/accessibility hazard and reads as 'broken render', not 'P.T. dread'. The design mentions a settings.reduceFlicker flag in risks but does NOT wire it into the integration steps — so the default build ships the strobe.

### Concrete fixes
- GRAIN: stop feeding seconds*60 into rand(). Drive grain off a small per-frame integer counter, not uTime. In core.render add `core._grainFrame=(core._grainFrame+1)%8192; postPass.uniforms.uGrainSeed.value=core._grainFrame;` and in-shader use `g=(rand(cell + uGrainSeed*1.37) - 0.5)*gAmp;` with cell=floor(vUv*uResolution*grainScale). The *1.37 decorrelates frames; the modulo keeps the magnitude <~8192 so float32 hash stays well-resolved. Verify by eye that grain visibly shimmers at 60fps and does NOT freeze when paused (it WILL freeze when paused since render still runs but counter advances — that's fine/desired).
- FOG: recompute with the real FogExp2 model exp(-(d*x)^2). To keep Granny ~50% visible at 8m you need density*8 ~= 0.83 => density ~= 0.104. So the heavier base of 0.16 is already too thick for the 8-12m approach. Concrete numbers: set RENDER.fogDensity base = 0.11 (not 0.16), fogDensityDread bump = 0.02 (not 0.03), HARD CAP effective density at 0.13 (not 0.22). At 0.13: 8m => exp(-(1.04)^2)=0.34 (silhouette readable), 6m => exp(-(0.78)^2)=0.54. Get the 'oppressive' feel from the color grade + halation + darker fixtures, NOT from raw density. If you want thicker near-fog without killing mid-range, this needs linear THREE.Fog with tuned near/far, not FogExp2 — but that's a bigger change; recommend keeping FogExp2 at 0.11-0.13.
- FLICKER BUDGET: gate ALL hard light failures behind a single settings flag and wire it into integration. Add to the updateLighting closure: `const flickerOK = !settings.reduceFlicker;` (pass settings into render or read a core._reduceFlicker set via onSettingsChange). When flickerOK is false: skip flashlight Poisson dropouts, skip the t*100 buzz, skip per-fixture blackouts; keep only the smooth brown-noise+sine flicker. Even when ON, cap simultaneous failures: enforce the design's >=0.25s flashlight min-gap AND add a global `core._lightFailLockout` so fixture blackouts and flashlight dropouts cannot fire in the same 100ms window. Lower fixture blackout lambda from 1.5 to 0.6 events/s/dread^2 — at dread=1 that's still ~1 blackout/1.6s per fixture across N fixtures, plenty.
- HALATION THRESHOLD IS IN THE WRONG COLOR SPACE — design correctly notes the pass runs pre-OutputPass on linear HalfFloat, then sets brightThreshold=0.65 as if it were sRGB. The flashlight at intensity 42 with ACES-to-come will have linear scene values well above 1.0 in the hotspot and well below 0.65 elsewhere. Either compute luma and threshold against a measured hotspot (instrument with GDBG: log max channel of tDiffuse center) or, simpler, threshold on `max(c-1.0,0.0)` so only genuinely over-1.0 (HDR) pixels bloom. Retune halTexel=3.0 only after confirming it bleeds from the flashlight cone, not from mid-grey walls.
- DESAT/LIFT ORDER vs ACES: applying additive lift (col*0.92 + 0.045) and 2x tint multiply in LINEAR space before ACES will not look like the SH 'flat ash' grade — ACES will roll the lifted blacks back down and desaturate the tint further. The design half-acknowledges this in risks ('muddying to grey') but ships the values anyway. Fix: do the desaturate (luma mix) in linear (fine), but apply the lift/crush/tint as a final touch AFTER tone mapping. Since this pass is before OutputPass, you cannot — so either (a) move the grade into OutputPass's territory by adding a tiny post-OutputPass tweak, or (b) accept linear-space grade and RETUNE empirically: expect to roughly double liftDread (~0.09) and drop tint x2 to x1.3. Do not ship the listed numbers as final; they are pre-calibration guesses.
- main.js HOOK: the design's snippet recomputes `const dread=clamp01(0.55*aware+0.45*prox)` but main.js line 249 ALREADY computes `prox` from AUDIO.heartbeat.dreadRadius. Reuse it: `core.setDread(chasing ? 1.0 : clamp01(0.55*aware+0.45*prox), dt);` placed AFTER line 251 (where `chasing` is defined) — the design says ~247-252 but `chasing` doesn't exist until line 251, so inserting at 250 as implied would reference an undefined var. Insert at line 252+.

### Cut scope
"Cut, in priority order: (1) HALATION entirely — it is the only real GPU cost (4 extra tDiffuse taps stacked on the existing 3 chroma taps = 7 fetches/pixel at full res), it's the highest-risk item for the linear/ACES threshold problem, and the 'warm bloom on the flashlight' reads almost identically if you instead just widen the flashlight penumbra and add the vignette+grade. Removing it makes the desktop frame-time question moot and deletes 2 of the 5 risks. (2) Per-fixture 16Hz buzz and per-fixture blackouts — keep ONLY the flashlight failure (one light, one Poisson stream, easy to cap) plus smooth fixture sag-by-dread; this removes the multi-source strobe hazard. (3) Breathing-vignette frequency change is free; keep it. (4) Fog COLOR roll (lerpColors + background.copy every frame) — keep the heavier-but-corrected static density and the desat grade; cut the animated color creep, it's the least visible element and adds a per-frame Color lerp + horizon-seam failure mode. Net: ship the smoothed-dread scalar + linear-space desat/lift/tint grade + corrected static fog + flashlight-only failure + breathing vignette. That is ~6 ALU ops/pixel, zero extra taps, no new strobe sources, and delivers 80% of the SH/P.T. read at near-zero perf and stability risk on both desktop and mobile."
