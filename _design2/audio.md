# COMPONENT: audio

## Summary
Add a new persistent "dread" subsystem to audio.js that runs in parallel with the existing music/granny/heartbeat systems without fighting them. It comprises five always-on synthesized layers built once at unlock (alongside buildMusic/buildAmbient): (1) a sub+detuned DRONE bed, (2) an irregular METALLIC groan/clang scheduler folded into the existing heartbeat look-ahead tick, (3) the signature RADIO STATIC whose gain+brightness is driven every frame from a combined distance/awareness "menace" scalar, (4) an oppressive room-tone BREATHING bed (slow filtered-noise swell, distinct from Granny's own breath), and (5) two scripted P.T. beats: a whisper sting and an all-audio "drop". Everything routes through a NEW dedicated bus 'dread' added to the bus list so it has its own mixer fader and is torn down/ducked uniformly. The only new per-frame coupling is one call AudioEngine.setMenace(dist, aware, chasing) from main.js; scripted beats are fired by granny.js on state transitions and by main.js. Mobile fallback collapses the 5 layers to 2 (drone + static only), drops the metallic scheduler and breathing, and halves oscillator counts, gated by an AudioEngine.setQuality('low') call from main.js using the existing MOBILE flag.

## Key decisions
- Add a SIXTH+SEVENTH? No — add exactly ONE new bus named 'dread' to the names array in buildBuses() (line 159) so dread has an isolated fader, predictable ducking, and clean teardown. Keep heartbeat/music/granny buses untouched so existing balance is preserved.
- Do NOT create a second setInterval. Fold metallic-groan and any dread scheduling into the EXISTING heartbeatTick() look-ahead loop (lines 980-1015) next to scheduleClockTicks(scheduleUntil) — reuses the 100ms HB_LOOKAHEAD window, the visibility-pause logic, and avoids drift. Add scheduleMetallic(scheduleUntil) call right after scheduleClockTicks.
- Radio static is the ONLY layer driven continuously per-frame; everything else is event/scheduler driven. Drive it from a single smoothed 'menace' scalar so it never jitters. menace = clamp01(0.55*aware + 0.45*proximity), proximity = clamp01((dread.staticRadius - dist)/dread.staticRadius), with chase forcing a floor of 0.85. Smooth in setMenace with setTargetAtTime tc=0.25 rising / 1.2 falling.
- Separate the dread breathing layer from Granny's breath layer (which lives in the granny chain, lines 686-705 and is gated by GRANNY_LAYER_GAINS). Dread breathing is ROOM tone (non-positional, always faint), Granny breath is HER body (positional, HRTF, occluded). They must not be the same node or they will double up during chase.
- Avoid frequency collisions with existing beds: ambient house drone is 42Hz (line 921), music calm drone is 55Hz (line 856). Place dread sub at 32-36Hz (below both) and detuned mid layers at 48/49.2Hz so the dread bed sits UNDER the music without phasing against the 55Hz.
- Scripted whisper and 'drop' are one-shots with debounce timestamps in S.dread so granny.js can call them every frame on a transition without spamming. The drop reuses the same bus-duck pattern already proven in jumpscare() (lines 1292-1303) but shorter and on the 'dread' path only-ish.
- Tie metallic-groan scheduling rate to menace: idle ~ every 18-32s, near ~ 9-16s, chase ~ 4-8s, so the house 'wakes up' as she closes in — the SH signature of the environment reacting.

Add S.dread to the stopAll teardown list (mirror S.music handling at lines 1366-1379). Add config block AUDIO.dread = { busGain:0.55, subHz:33, subGain:0.5, midHzA:48, midHzB:49.2, midDetune:6, midGain:0.16, droneNoiseHz:160, droneNoiseGain:0.05, staticRadius:14, staticMinGain:0.0, staticMaxGain:0.5, staticMinHz:300, staticMaxHz:5200, staticHpHz:500, menaceRiseTC:0.25, menaceFallTC:1.2, breathGain:0.10, breathLfoHz:0.22, groanIntervalIdle:[18,32], groanIntervalNear:[9,16], groanIntervalChase:[4,8], groanGain:0.4, whisperDebounce:8, whisperGain:0.35, dropDebounce:20, dropDuckTo:0.12, dropHold:0.5, dropRelease:1.4 } and add 'dread':0.55 into AUDIO.busGains.

## Algorithms
- DRONE (buildDread): subOsc = sine @ AUDIO.dread.subHz(33), into subGain(0.5). midA = triangle @ 48Hz, midB = triangle @ 49.2Hz (detune via .frequency offset, NOT detune cents, to guarantee a ~1.2Hz beat-frequency slow throb), each through gain 0.16 into droneOut. A pink-ish rumble: noiseSource -> lowpass @160Hz Q0.7 -> gain 0.05 -> droneOut. droneOut.gain = 1, droneOut -> S.buses.dread. Add a very slow LFO (sine 0.05Hz, depth 4Hz) onto subOsc.frequency for living instability. All sources start(t) once.
- RADIO STATIC (buildDread): src = noiseSource(); hp = highpass @ AUDIO.dread.staticHpHz(500) to give it the thin transistor hiss; lp = lowpass whose frequency IS the brightness control (starts at staticMinHz 300); gain = static.gain (starts 0). Chain src->hp->lp->gain->staticOut->S.buses.dread. Optional crackle: a second noiseSource through a square-LFO-gated VCA (LFO 11Hz, asymmetric) summed in at 0.3x for the irregular popping — skip on low quality. start(t) once. setMenace maps menace m: lp.frequency target = lerp(staticMinHz 300, staticMaxHz 5200, m); gain target = lerp(staticMinGain 0, staticMaxGain 0.5, m*m) (square for a more sudden swell near her). Both via setTargetAtTime using rising/falling tc.
- BREATHING ROOM-TONE (buildDread): src = noiseSource -> bandpass center 350Hz Q0.8 -> breathVCA -> breathOut(gain=breathGain 0.10) -> bus. breathVCA.gain driven by LFO sine @0.22Hz (~2.7s per breath) depth 0.5 + constant bias 0.5 so it swells 0..1; add a second sllow LFO at 0.205Hz on the bandpass center (depth 120Hz) so inhale/exhale shift timbre. Keep gain low and constant (not menace-driven) — it is the oppressive ever-present room.
- METALLIC GROAN (scheduleMetallic + spawnGroan): in the heartbeat look-ahead, while S.dread.groan.nextTime < scheduleUntil: spawnGroan(t); then pick interval range by current menace band (m<0.25 idle, m<0.6 near, else chase) and set nextTime += rand(range[0],range[1]). spawnGroan(t): pick base freq rand 70-140Hz. Two detuned sawtooths (detune +/- rand 8-18 cents) -> waveshaper(makeShaperCurve(3)) -> bandpass sweeping 180->90Hz over 1.6s (groan) OR for a 'clang' variant (20% chance) a metallic ring: 4 inharmonic sine partials (f, f*2.76, f*5.4, f*8.9) through a fast-decay gain (expRamp to TINY over 0.9s) + a short highpassed noise tick. Envelope: gain ramp TINY->groanGain(0.4)*(0.5+0.5m) over 0.25s, hold, expRamp TINY over 1.4-2.0s. Route through an equalpower beginTransient on a far-ish random position OR straight to S.buses.dread (non-positional, distant). Use scheduleStingCleanup for node disposal.
- WHISPER STING (whisper(pos)): debounce via now()-S.dread.lastWhisper > whisperDebounce(8); set lastWhisper. Synthesis: noiseSource -> bandpass center sweeping 1200->2400Hz over 0.6s Q6 (the sibilant 'sss') -> gain ramp TINY->whisperGain(0.35) over 0.08s -> exp TINY over 0.7s; add a faint ring-mod by multiplying with a 4Hz tremolo for syllable feel. Route through beginTransient('dread', pos) so it pans to Granny's bearing (a voice from her direction) and gets distance falloff. Self-cleans via onended.
- DREAD DROP (dreadDrop()): debounce now()-lastDrop>dropDebounce(20). Cancel+ramp the master OR a chosen set of buses down hard then back: ramp buses ambient,music,dread,sfx,heartbeat to base*dropDuckTo(0.12) over 0.04s, hold dropHold(0.5)s of near-silence (the P.T. vacuum), then linearRamp back to base over dropRelease(1.4)s. Simultaneously schedule a single deep sub-thump (sine 40->28Hz, gain 0.6 exp to TINY over 0.8s) on the dread bus as the 'pressure' hit, and re-trigger a brief static spike (briefly force static.gain to 0.4 then let setMenace recover). Mirrors jumpscare's bus-duck math (lines 1296-1302) but shorter.

## Tunables
- AUDIO.dread.busGain (0.55) — overall dread bed loudness vs music(0.6)/ambient(0.5); keep below music so it underpins not masks
- subHz 33 / midHzA 48 / midHzB 49.2 — sub pitch and the ~1.2Hz throb beat-frequency; widen the A/B gap for faster throb
- staticRadius 14 (matches GRANNY.hearingBaseRadius) — distance at which static begins; staticMaxGain 0.5 and the m*m curve control how aggressively it swells near her
- staticMinHz 300 / staticMaxHz 5200 — how 'bright/close' the radio gets at full menace; the SH tell
- menaceRiseTC 0.25 / menaceFallTC 1.2 — how fast static reacts in vs out; fast-in slow-out for dread tail
- groanIntervalIdle/Near/Chase ranges + groanGain 0.4 — frequency and loudness of the house groans per threat band
- breathGain 0.10 / breathLfoHz 0.22 — room breathing loudness and rate (lower Hz = slower, more oppressive)
- whisperDebounce 8 / whisperGain 0.35 and dropDebounce 20 / dropDuckTo 0.12 / dropHold 0.5 / dropRelease 1.4 — scripted-beat spacing and intensity
- AUDIO.busGains.dread 0.55 — independent mixer fader, also settable live via existing setBusVolume('dread', v)

## Mobile fallback
Add AudioEngine.setQuality(q) storing S.dread.quality. buildDread() branches on quality: LOW = build ONLY the drone (sub + ONE mid osc + lowpassed noise) and the radio static (single noiseSource->hp->lp->gain, NO crackle VCA). Skip the breathing layer and skip the metallic groan scheduler entirely (scheduleMetallic returns immediately when quality==='low'). Whisper and dreadDrop remain (they are cheap one-shots and are key flavor) but dreadDrop ducks fewer buses. Net concurrent persistent oscillators on mobile: ~3 (sub, one mid, two noise sources) vs ~9 on desktop. Call site: main.js after MOBILE is defined (after line 24) -> AudioEngine.setQuality(MOBILE ? 'low' : 'high'); BEFORE the context is unlocked is fine because buildDread() reads S.dread.quality at build time inside doUnlock(); ensure setQuality just stores the flag and, if S.dread already built (quality changed mid-session), mutes the extra layers' output gains to 0 rather than rebuilding. Because static is driven by setMenace which is called unconditionally from main.js, no separate mobile branch is needed at the call site.

## Pitfalls
- Persistent BufferSource/Oscillator nodes must be start()ed exactly ONCE in buildDread() and must be added to S.dread.sources so stopAll() can stop() them — forgetting this leaks voices and throws on ctx.close(). Mirror buildMusic() exactly.
- Do NOT setTargetAtTime to exactly 0 on the static lowpass frequency or any exp ramp — use the existing approach()/expRampTo() helpers which guard TINY. Static gain CAN go to 0 via linear/setTarget (it's a gain), but lp.frequency target 0 is invalid; clamp staticMinHz>=200.
- menace must be smoothed inside setMenace (setTargetAtTime), NOT recomputed raw each frame onto the param, or the static will zipper because main.js runs at frame rate not audio rate. Store menaceTarget and apply with rising/falling tc using S.ctx.currentTime.
- Whisper routes through beginTransient('dread', pos) — beginTransient already counts against maxTransientVoices(8). Frequent whispers during rapid investigate flicker could cull footsteps; the debounce (8s) and the rising-edge-only trigger in granny.js prevent this. Keep whisper out of the polyphony-heavy paths.
- Do NOT reuse Granny's breath nodes for room breathing — they are gated to 0 in idle (GRANNY_LAYER_GAINS.idle.breath=0) and are HRTF+occluded; the room bed must be independent and non-positional.
- The metallic scheduler shares heartbeatTick which is paused on document.hidden (visibilitychange handler lines 1098-1115) and resets clockNextTime — also reset S.dread.groan.nextTime = tnow()+1 in that handler, else a burst of backlogged groans fires on tab refocus.
- jumpscare()/dreadDrop() both manipulate bus gains with cancelScheduledValues; if they overlap they fight. Guard dreadDrop with its debounce AND skip it if a jumpscare is in flight (track S._jumpAt timestamp).
- Adding 'dread' to the bus names array changes buildBuses; ensure AUDIO.busGains.dread exists or it defaults to 0.8 (line 162) which would be too loud — set it explicitly to 0.55 in config.

## CRITIQUE worksProb=0.72
### Fatal flaws
- LOW-END LIMITER PUMPING IS UNDERSTATED, NOT MITIGATED. The existing limiter is brutal: threshold -3dB, ratio 20:1, attack 0.001s, release 0.1s (config.js line 121). You are stacking a THIRD always-on sub layer (33Hz @ subGain 0.5) under the existing ambient 42Hz (gain 0.12*0.5 bus) and music 55Hz drone. With a 0.1s release, every heartbeat lub-dub (60->30Hz, peak 0.7+ at chase) and every dreadDrop sub-thump (40->28Hz @ 0.6) will gain-pump the ENTIRE mix audibly because the limiter sees the summed sub energy. The design says 'verify no pumping by ear' — that is exactly the hand-wave. At 33Hz the period is 30ms; with attack 1ms the limiter clamps the waveform itself, adding distortion, not just gain reduction. This WILL pump on an integrated build.
- menace SCALAR ASSUMES INPUTS THE CALL SITE DOESN'T PASS CLEANLY. The design says setMenace(dist, aware, chasing) reuses 'already-computed dist/aware/chasing locals' at main.js ~252. True — dist (line 247), aware (248), chasing (251) all exist. BUT proximity is computed inside setMenace against dread.staticRadius=14, while main.js ALREADY computes prox against AUDIO.heartbeat.dreadRadius=12 (line 249) for the heartbeat. Two different radii driving two different dread systems off the same distance is an inconsistency that will make the static and heartbeat swell at visibly different distances — not a crash, but a tuning trap that reads as 'broken' to the client. The design never reconciles 12 vs 14.
- dreadDrop() AND jumpscare() FIGHT OVER THE SAME BUS GAINS WITH NO REAL GUARD. Both call cancelScheduledValues on ambient/music/heartbeat/sfx gains. The design's pitfall says 'skip dreadDrop if a jumpscare is in flight (track S._jumpAt timestamp)' — but S._jumpAt DOES NOT EXIST in the current jumpscare() (lines 1287-1334); it returns true with no timestamp and no in-flight flag. The chase-begin rising edge (main.js) that fires dreadDrop can coincide within ~100ms of onCatch()->jumpscare() (main.js line 138), because a lunge catch happens during chase. Result: dreadDrop ramps buses back to base over 1.4s while jumpscare is mid-duck, or vice-versa — the jumpscare loses its silence-vacuum. This is a real audible bug on the most important moment in the game.
- MOBILE setQuality TIMING IS BACKWARDS FROM ITS OWN PITFALL. Design says call setQuality after MOBILE is defined (main.js after line 24), and buildDread() reads quality at build time in doUnlock(). But doUnlock() is gesture-triggered and may fire on the FIRST pointerdown/keydown anywhere (unlock listeners attached in init() at line 20, BEFORE line 24). On a fast mobile tap during the loading screen, doUnlock can run before the setQuality(MOBILE?'low') line executes — actually no: that line is synchronous at module top-level after line 24, and unlock needs a user gesture which can't precede module eval. So this is safe BUT the design's own claim 'setQuality just stores the flag and if already built mutes extra layers' means a mid-session toggle path exists that is never exercised and adds dead complexity.

### Concrete fixes
- FIX THE LOW END BEFORE ADDING IT. Give the dread bus its OWN highpass-free but gain-limited path: insert a dedicated DynamicsCompressor on the dread bus (threshold -10, ratio 4, attack 0.005, release 0.25) BEFORE it hits master, so dread's own sub is tamed locally and doesn't drive the master limiter into the 33Hz waveform. AND drop subGain from 0.5 to 0.30 and AUDIO.busGains.dread from 0.55 to 0.40. Net sub energy into master should be roughly equal to ambient's current 42Hz contribution, not additive on top. Measure: sum of (subGain*busGain.dread) + (ambient drone 0.12*0.5) + (music drone ~0.5*0.6) should leave >=6dB headroom below limiter threshold -3.
- PASS ONE menace-RELEVANT RADIUS. Either set AUDIO.dread.staticRadius = AUDIO.heartbeat.dreadRadius (12, not 14) so static and heartbeat track together, OR pass the already-computed prox from main.js into setMenace(prox, aware, chasing) and delete the internal proximity recompute. The second is cleaner and removes the 12-vs-14 divergence entirely. menace = clamp01(0.55*aware + 0.45*prox), chase floor 0.85, smoothed with setTargetAtTime rise 0.25 / fall 1.2 — keep that part.
- ADD A REAL CROSS-GUARD. In jumpscare() set S._jumpAt = ctx.currentTime at the top (one line). In dreadDrop(): if (tnow() - (S._jumpAt||-99) < 2.0) return; before doing anything. Conversely have jumpscare() ALSO cancel any dread-drop ramp by including 'dread' in its duckBuses (the design already adds this — good) AND re-asserting setValueAtTime(base, t0) on those buses so a half-finished dreadDrop ramp is overwritten. Without setting S._jumpAt this guard is a no-op; that one assignment is mandatory.
- STATIC ZIPPER GUARD IS RIGHT, KEEP IT, BUT CLAMP THE LP FLOOR. Design correctly says smooth menace in setMenace via setTargetAtTime, not per-frame param writes — keep that. Enforce staticMinHz >= 200 (design says clamp; make it a hard Math.max(200, ...) in code, not a config-only convention, because a future tuner WILL set it to 0 and exponential-target-0 throws). Use approach()/expRampTo() helpers (lines 88-99) exclusively for lp.frequency.
- GROAN SCHEDULER: reset S.dread.groan.nextTime in the EXISTING visibilitychange handler (lines 1098-1115) right next to the clockNextTime reset at line 1111, set it to tnow()+1. The design names this pitfall but the fix must land in that specific handler or you get a backlog burst of 4-8 groans on tab refocus. Also: scheduleMetallic must early-return when quality==='low' (design says so) — verify it's the FIRST line of the function, before the while-loop reads nextTime, or low-quality still advances the clock.

### Cut scope
"If perf or the limiter-pumping fight forces cuts, drop to TWO layers permanently (not just on mobile): keep (1) the radio static driven by setMenace — it IS the Silent Hill signature and the single highest-value element — and (2) the metallic groan scheduler folded into heartbeatTick (cheap, event-driven, sells 'the house reacts'). CUT the dread sub-drone entirely (it is the sole cause of the limiter pumping and overlaps two existing 42/55Hz beds that already provide low-end dread), CUT the room-tone breathing layer (it doubles Granny's breath and is the least perceptible under fog/heartbeat), and KEEP the whisper + dreadDrop one-shots (cheap, high flavor, fire on edges only). This removes ~5 of the ~9 always-on nodes, eliminates the worst stability risk, and loses almost none of the perceived dread because static+groans+existing beds already carry it. Net desktop persistent oscillators drop from ~9 to ~2, making it identical to the mobile fallback — which is a feature, not a regression."
